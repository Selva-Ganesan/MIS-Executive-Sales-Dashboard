# MIS Executive Sales Dashboard — Excel

## Project Overview

An interactive sales reporting dashboard developed in Microsoft Excel to monitor business performance, sales targets, order status, profitability, and returns.

## Tools Used

* Microsoft Excel
* Power Query
* PivotTables and PivotCharts
* Excel formulas and KPI calculations
* Interactive slicers

## Key Performance Indicators

* Total Realized Sales
* Total Completed Orders
* Average Order Value (AOV)
* Gross Profit Margin
* Target Achievement
* Return Rate
* Pending Orders

## Data Preparation

* Removed duplicate records.
* Cleaned and standardized inconsistent data.
* Handled missing values.
* Corrected date-format inconsistencies.
* Checked employee and product master-data matches.
* Compared recorded sales against calculated sales.
* Integrated return information for analysis.

## Dashboard Features

* Interactive Region slicer
* Interactive Category slicer
* KPI cards
* Sales performance reporting
* PivotTable-based analysis

## Business Objectives

* Monitor sales performance against targets.
* Analyze performance across regions and product categories.
* Track pending orders and returns.
* Support management reporting and operational decisions.

## Skills Demonstrated

Excel reporting, Power Query, data cleaning, KPI reporting, PivotTables, dashboard design, and business analysis.

## Note

This is a portfolio project using a simulated retail dataset. Figures and KPI calculations should be validated against the underlying data before being used for business decisions.
